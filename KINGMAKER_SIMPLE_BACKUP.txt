============================================================
MAKE THE PHYSICAL BACKUP NOW
============================================================

1. Open Terminal on the Mac mini.

2. Go to your truely-collectables folder.
   EASY WAY:
   - Type: cd 
   - Leave a space after cd.
   - Drag the truely-collectables folder from Finder into Terminal.
   - Press Return.

3. Run these commands ONE AT A TIME:

   git fetch origin

   git checkout backup/kingmaker-certified-2026-08-07-recovery

   zsh ./KINGMAKER_BACKUP_NOW.command

IMPORTANT: Do NOT run chmod +x on the tracked .command files before backup.
Changing the executable bit can make Git report the recovery branch as dirty,
and the golden backup correctly refuses a dirty tracked state.

If the backup reports other existing local tracked changes, preserve them first.
Do not use git reset --hard. The detailed guide explains the safe temporary-clean
procedure.

4. DO NOT call the backup good unless it ends with exactly:

   SUCCESS - KINGMAKER GOLDEN BACKUP VERIFIED

5. In Finder press Command + Shift + G and enter:

   ~/Backups/KINGMAKER-GOLDEN-2026-08-07

6. Copy that ENTIRE folder to an external SSD or USB drive.

7. Do NOT upload that folder publicly. The archive can contain .env secrets.

8. Return the normal repository to main when your preserved local work has been restored:

   git checkout main

============================================================
IF KINGMAKER BREAKS LATER
============================================================

1. DO NOT delete the broken/old folder.

2. Copy the complete backup folder from the external drive back to:

   ~/Backups/KINGMAKER-GOLDEN-2026-08-07

3. Open Terminal.

4. Run:

   cd ~/Backups/KINGMAKER-GOLDEN-2026-08-07

   zsh ./KINGMAKER_RESTORE.command

5. The restore NEVER overwrites your old repository. It creates a new folder similar to:

   ~/KINGMAKER-Recovery-20260807-xxxxxx

6. DO NOT continue unless it ends with:

   LOCAL KINGMAKER RECOVERY SUCCESS

7. Then follow KINGMAKER_RECOVERY_GUIDE.md section:

   FINAL PRODUCTION RECOVERY
