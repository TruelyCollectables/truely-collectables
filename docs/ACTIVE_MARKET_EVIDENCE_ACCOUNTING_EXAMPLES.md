# Evidence accounting examples

A search that observes six external listings must show a reconciled equation such as:

`6 external = 0 verified + 2 scouting + 2 packaging rejected + 2 identity rejected + 0 auction-only`

The seller's own eBay listing is recorded separately and never included in the external total or competitor pricing.

Identity-rejected entries retain the listing title, URL, item price, shipping, search queries, source lane, and plain-English rejection reasons such as wrong player, wrong card number, numbered variant, autograph mismatch, relic mismatch, graded/raw mismatch, set mismatch, or parallel mismatch.
