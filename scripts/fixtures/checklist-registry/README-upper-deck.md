# Upper Deck proof fixtures

These HTML files are deliberately small, source-shaped validation fixtures built from rows published on Upper Deck's official checklist pages. They are marked `test_batch` and are not complete checklists.

- `2024-25-upper-deck-series-1.sample.html` covers Lane Hutson Young Guns, Clear Cut, Deluxe /250, Outburst Red /25, Outburst Gold 1/1, Canvas Young Guns, Black and White, and Printing Plates /4.
- `2025-26-upper-deck-allure.sample.html` covers Ivan Demidov Rookies Base, Black Rainbow, Orange Slice, Gold Glitter Bomb /199, Hitting Thier Groove, Golden Treasures 1/1, and SP Auto.

The live backfill step must archive and validate the complete official HTML pages separately. These fixtures must never be counted as full Registry coverage.
